<span id="cinnamon-js-ui-settings-XletSettingsBase.description"></span>

## Description

This object provides methods for binding settings to object properties,
connecting to signal change events, and getting and setting values. This
class should not be directly, but rather through one of the wrapper
classes
(<a href="cinnamon-js-ui-settings-AppletSettings.html" class="link"
title="Settings.AppletSettings"><code
class="code">AppletSettings</code></a>,
<a href="cinnamon-js-ui-settings-DeskletSettings.html" class="link"
title="Settings.DeskletSettings"><code
class="code">DeskletSettings</code></a>, or
<a href="cinnamon-js-ui-settings-ExtensionSettings.html" class="link"
title="Settings.ExtensionSettings"><code
class="code">ExtensionSettings</code></a>)

</div>

### bindWithObject ()

``` programlisting
boolean
bindWithObject (object     bindObject,
                string     key,
                string     applet_prop,
                function   callback,
                           user_data);
```

Like bind this allows you to bind a setting to a property on an object.
But unlike <a
href="cinnamon-js-ui-settings-XletSettingsBase.html#cinnamon-js-ui-settings-XletSettingsBase-bind"
class="link" title="bind ()"><code class="code">bind</code></a>, this
function allows you to specify the bindObject to which the property will
be bound.

<div class="refsect3">

<span id="id-1.2.19.3.7.2.5"></span>

#### Parameters

<div class="informaltable">

|             |                                                                                                          |     |
|-------------|----------------------------------------------------------------------------------------------------------|-----|
| bindObject  | (optional) the object to which the setting will be bound or null to use the bindObject passed to `_init` |     |
| key         | the id of the setting                                                                                    |     |
| applet_prop | the variable name that is used to hold the setting (eg. `this.value` passes as `"value`")                |     |
| callback    | (optional) the function to call when the setting changes                                                 |     |
| user_data   | (optional) any extra data/object you wish to pass to the callback                                        |     |

</div>

</div>

### unbindWithObject ()

``` programlisting
boolean
unbindWithObject (object   bindObject,
                  string   key);
```

Removes the binding on an object. If you have bound `key` to multiple
objects, this will only remove the one bound to `bindObject`. If you
wish to remove all bindings, or you used <a
href="cinnamon-js-ui-settings-XletSettingsBase.html#cinnamon-js-ui-settings-XletSettingsBase-bind"
class="link" title="bind ()"><code class="code">bind</code></a> or <a
href="cinnamon-js-ui-settings-XletSettingsBase.html#cinnamon-js-ui-settings-XletSettingsBase-bindProperty"
class="link" title="bindProperty ()"><code
class="code">bindProperty</code></a> to bind the setting, it is
recommended that you use `unbindPropery` instead.

<div class="refsect3">

<span id="id-1.2.19.3.7.5.5"></span>

#### Parameters

<div class="informaltable">

|            |                                                              |     |
|------------|--------------------------------------------------------------|-----|
| bindObject | (optional) the object from which the setting will be unbound |     |
| key        | the previously bound key to remove                           |     |

</div>

</div>

<div class="refsect3">

<span id="id-1.2.19.3.7.5.6"></span>
