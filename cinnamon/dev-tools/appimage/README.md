# CurbSoftware Desktop Widgets

One AppImage that installs CurbSoftware widgets for the desktop you
are running: Cinnamon desklets and applets, GNOME Shell extensions,
and KDE Plasma plasmoids.

Open it to manage them. The window detects your OS and desktop, lists
only the matching variants, and can install or remove files, add or
drop instances on the panel or the desktop, and update itself from
GitHub Releases.

Download the latest AppImage from this repository's Releases page.

If you only want one widget, use the per-desktop repos instead
(`gnome-world-clock`, `kde-world-clock`, and the rest). The AppImage
is the all-in-one path.

This tree is generated from
[CurbSoftware/cinnamon-monorepo](https://github.com/CurbSoftware/cinnamon-monorepo).
Do not edit it by hand.
