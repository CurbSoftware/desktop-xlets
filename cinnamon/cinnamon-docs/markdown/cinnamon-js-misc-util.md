<span id="cinnamon-js-misc-util.description"></span>

## Description

This file includes certain useful utility functions such as running
external commands. It is generally a good idea to use the functions
defined here instead of tapping into GLib directly since this adds some
wrappers around the functions that make them more Cinnamon-friendly and
provides helpful error messages.

### tryFn ()

``` programlisting
any
tryFn (function   callback,
       function   errCallback);
```

Try-catch can degrade performance in the function scope it is called in.
By using a wrapper for try-catch, the function scope is reduced to the
wrapper and not a potentially performance critical function calling the
wrapper. Use of try-catch in any form will be slower than writing
defensive code.

<div class="refsect3">

<span id="id-1.3.3.2.5.13.5"></span>

|-------------|----------------------------------------|-----|

| errCallback | The function to call on error.         |     |

</div>

<span id="cinnamon-js-misc-util-unref"></span>

### unref ()

``` programlisting

unref (object   object,
       array    reserved);
```

This will iterate `object` and assign null to every property value
except for keys specified in the `reserved` array. Calling unref() in an
object that has many references can make garbage collection easier for
the engine. This should be used at the end of the lifecycle for classes
that do not reconstruct very frequently, as GC thrashing can reduce
performance.

<div class="refsect3">

<span id="id-1.3.3.2.5.19.5"></span>

#### Parameters

<div class="informaltable">

|          |                                                                 |     |
|----------|-----------------------------------------------------------------|-----|
| object   | Object to be nullified.                                         |     |
| reserved | List of special keys (string) that should not be assigned null. |     |

</div>

</div>

### splitByGlyph ()

``` programlisting
array
splitByGlyph (string   str);
```

Converts a string, possibly containing multiple codepoint unicode
characters (e.g. emoji), into an array of unicode graphemes clusters
(glyphs). For example: "👩‍👩‍👧‍👧😃".length === 13, but splitByGlyph("👩‍👩‍👧‍👧😃")
returns \["👩‍👩‍👧‍👧", "😃"\] which is length 2.

<div class="refsect3">

<span id="id-1.3.3.2.5.22.5"></span>

#### Parameters

<div class="informaltable">

|     |                            |     |
|-----|----------------------------|-----|
| str | The string to be converted |     |

</div>

</div>

<div class="refsect3">

<span id="id-1.3.3.2.5.22.6"></span>

#### Returns
